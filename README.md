# Chilo's Kitchen 2.0

A simple, responsive, single-page restaurant website built using **vanilla JavaScript**, **HTML**, and **CSS**, as part of the [Odin Project](https://www.theodinproject.com/) curriculum.

---

##  Features

-  **Modular JavaScript** using ES6 modules
-  **Dark mode design** with modern color theming and smooth transitions
-  **Single-page navigation** between:
  - **Home** – Welcoming intro and restaurant description
  - **Menu** – A list of dishes with names, descriptions, prices, and images
  - **Contact Us** – Contact info, location, and opening hours
-  Fully structured with reusable DOM logic for easy maintenance
